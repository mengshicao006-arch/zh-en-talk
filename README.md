# 中英实时语音互译

中英实时语音互译工具，支持 Windows 与手机远程使用。

对着说、停一下，软件自动识别、翻译并朗读。说中文就读英文，说英文就读中文。适合面对面口语、戴耳机对话。

电脑上是 Windows 桌面软件。也可以让家里电脑开着，出门用手机耳机远程说。

MIT 开源。

## 它做什么

- 一直听，不用每句都按键
- 说完稍停，自动翻译
- 中文 ↔ 英文，只读译文本身
- 翻译用 DeepSeek
- 识别用豆包流式语音识别 2.0
- 电脑朗读用豆包语音合成 2.0（可选系统音色）
- 可扫码用手机麦克风和耳机，电脑继续做识别和翻译

## 你需要准备

- Windows 电脑
- [Node.js](https://nodejs.org/)（建议 20 或更新）
- [DeepSeek API Key](https://platform.deepseek.com/)（`sk-` 开头）
- 豆包语音控制台：
  - 流式语音识别模型 2.0 的 API Key（UUID，不是方舟 `ark-` Key）
  - 语音合成模型 2.0 的 **Access Token**（旧控制台点小眼睛复制的那串，不是 Secret Key）
  - 如需合成，还要有对应 APP ID

密钥只存在你自己电脑上，不要写进 Git。

## 安装和启动

在项目目录执行：

```bat
npm install
npm run dev
```

或双击：

- 桌面「中英互译」快捷方式
- 或本目录的 `启动.bat` / `start-dev.cmd`

**不要在 Cursor 里点这些文件。** 请在资源管理器或桌面双击。

会弹出一个黑色命令窗口，**请一直开着**。再过几秒出现「中英互译」窗口。关掉黑窗口，软件就会退出。

## 第一次使用（电脑）

1. 填写 **DeepSeek API Key**，点保存。
2. 填写 **豆包语音合成 2.0 Access Token**，点保存。
3. 识别用的豆包 API Key 请放到本机配置，任选一种：
   - 复制 `.env.example` 为 `.env`，填写 `DOUBAO_ASR_KEY=`（以及需要的 `DOUBAO_TTS_KEY`、`DOUBAO_APP_ID`）
   - 或写在 `%APPDATA%\zh-en-talk\config.json` 的 `doubaoKey` 字段
4. 选择麦克风、扬声器（尽量选耳机）。
5. 可选：选中文音色、英文音色。
6. 点 **开始说话**。允许使用麦克风。
7. 对着耳机说，说完停大约一秒，就会出译文并朗读。再说可以打断朗读。
8. 点 **停止** 结束。

右上角：

- **重启**：刷新界面并重新开通手机通道（二维码会变）
- **关闭**：退出软件

## 出门用 iPhone

电脑要保持开机、不要休眠，软件窗口开着。

1. 等窗口里「出门用 iPhone 耳机」出现二维码（第一次可能要等一会儿）。
2. iPhone 插上或连上耳机。
3. 用相机扫码后，点 **在 Safari 中打开**，不要停在相机预览里。
4. 允许麦克风，点 **开始说话**。
5. 对着耳机说。识别和翻译在家里电脑上完成，声音从手机耳机里出来。
6. 页面不要切走、尽量别锁屏。

注意：

- 每次关掉软件再开，二维码都会变，旧码作废。
- 若一直没有二维码，或扫了打不开：电脑开了 VPN/代理时，请把 `%APPDATA%\zh-en-talk\cloudflared.exe` 设为 **直连 / 绕过**，再点重启。
- 手机链路会绕 Cloudflare，可能比电脑本地慢一些。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm install` | 安装依赖 |
| `npm run dev` | 开发方式启动（Vite + Electron） |
| `npm start` | 先打包再启动 |

## 不要提交这些

- `.env`（填了密钥的）
- `%APPDATA%\zh-en-talk\config.json`
- `node_modules`

`.env.example` 可以留在仓库里当模板。
