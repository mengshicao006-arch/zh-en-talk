# 中英互译

对着麦克风说中文，读出英文；说英文，读出中文。电脑上用耳机对话，也可以扫码用 iPhone 耳机远程说。

MIT 开源。

## 电脑上使用

1. 安装 [Node.js](https://nodejs.org/)
2. 双击桌面「中英互译」快捷方式，或在本目录运行：

```bat
npm install
npm run dev
```

3. 在窗口里保存 DeepSeek API Key、豆包语音识别 Key、语音合成 Access Token
4. 点「开始说话」

黑窗口要一直开着。关掉窗口或点「关闭」，软件就会退出。

## 手机远程

电脑保持开机、不要休眠。窗口出现二维码后，用 **Safari** 扫码（不要停在相机预览里）。每次重新打开软件，二维码都会变。

若扫码打不开，把代理里的 `cloudflared.exe` 设为直连后再重启。

## 密钥

密钥保存在本机，不要提交到 Git。复制 `.env.example` 为 `.env` 也可以，但不要把填好的 `.env` 上传。
